# RISC-V 流水线时序分析功能更新

## 功能概述

本次更新在 RISC-V 分析部分新增了流水线时序分析能力，核心代码位于：

```text
RISC-V/src/simulator.py
```

该模块用于对 RISC-V 程序中的基本块进行指令级流水线模拟。相比只根据指令数量或固定周期估计程序执行时间的方式，新增模块能够进一步考虑指令类型、执行单元、寄存器依赖、访存开销以及 Cache 命中缺失带来的流水线阻塞，从而为后续 WCET 分析提供更细粒度的 basic block 周期估计基础。

---

## 新增内容

本次主要新增：

```text
RISC-V/src/simulator.py
```

该文件实现了一个面向 RISC-V 指令序列的流水线模拟器，主要功能包括：

- 将 RISC-V 指令转换为流水线内部指令对象；
- 识别整数、跳转、分支、乘法、除法、访存、浮点和向量等不同类型指令；
- 模拟指令进入流水线后的分派、执行和提交过程；
- 维护寄存器读写依赖，避免错误的乱序执行；
- 使用 ROB 保证指令提交顺序；
- 根据执行单元类型统计不同指令的执行周期；
- 支持结合 I-Cache / D-Cache 命中缺失信息加入额外 stall；
- 输出 basic block 级别的流水线周期估计结果。

---

## 流水线分析流程

新增流水线模块的整体分析流程如下：

```text
RISC-V 指令序列
        ↓
指令类型识别
        ↓
寄存器依赖分析
        ↓
执行单元分派
        ↓
ROB 顺序提交
        ↓
Cache miss penalty 注入
        ↓
Basic Block 周期估计
```

通过该流程，系统可以从单纯的控制流分析进一步扩展到处理器执行层面的时序分析。

---

## 支持的指令类别

流水线模拟器会根据 RISC-V 指令的类型将其分派到不同执行单元，当前主要支持以下类别：

```text
INTEGER        整数计算指令
JUMP           跳转指令
BRANCH         条件分支指令
MULTIPLY       乘法指令
DIVISION       除法指令
MEMORY         load / store 访存指令
SINGLE_FLOAT   单精度浮点指令
VECTOR         向量指令
```

不同类型的指令具有不同的执行路径和周期行为，因此该模块可以比固定周期模型更准确地反映 RISC-V 程序在流水线结构上的执行开销。

---

## Cache-aware 时序建模

本次流水线分析不是孤立地统计指令周期，而是预留了与 Cache 分析结果结合的接口。

在已有 RISC-V 静态分析流程中，Cache 分析会对指令访问和数据访问生成命中 / 缺失分类结果。流水线模拟器可以根据这些结果对取指和访存阶段加入额外 penalty：

```text
I-Cache miss → 取指阶段 stall
D-Cache miss → load / store 阶段 stall
Cache hit    → 正常流水线执行
```

因此，Cache miss 不再只是一个分类结果，而是可以进一步转化为流水线执行过程中的时间开销。

---

## Basic Block 级周期估计

新增模块以 basic block 为主要分析粒度。对于每个 basic block，模拟器会读取其中的 RISC-V 指令序列，并估计该 basic block 在流水线中的执行周期。

这种设计适合与 CFG 和 ILP 形式的 WCET 分析结合：

```text
CFG basic block
        ↓
流水线模拟
        ↓
basic block cycle
        ↓
路径约束 / ILP 建模
        ↓
程序级最坏执行时间估计
```

这样可以使每个 CFG 节点的代价更加贴近底层处理器结构，而不是使用统一的默认周期。
